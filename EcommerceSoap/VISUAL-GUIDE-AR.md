## 🔄 دورة حياة الطلب - Request Lifecycle

### مثال: العميل يريد رؤية جميع المنتجات

```
الخطوة 1: العميل يرسل طلب SOAP
═══════════════════════════════════
┌─────────────┐
│   العميل    │ يرسل طلب XML
│   Client    │ ───────────────────┐
└─────────────┘                    │
                                   ▼
                        ┌──────────────────────┐
                        │ ProductService.asmx  │
                        │ يستقبل الطلب         │
                        └──────────┬───────────┘
                                   │
                                   
الخطوة 2: الخدمة تعالج الطلب
═════════════════════════════
                                   │
                                   ▼
                        ┌──────────────────────┐
                        │  ProductSoapService  │
                        │  (يحلل رسالة XML)   │
                        └──────────┬───────────┘
                                   │ يستدعي
                                   ▼
                        ┌──────────────────────┐
                        │   ProductService     │
                        │   (منطق الأعمال)    │
                        └──────────┬───────────┘
                                   │ يقرأ
                                   ▼
                        ┌──────────────────────┐
                        │   Product Models     │
                        │   (البيانات)        │
                        └──────────┬───────────┘
                                   │
                                   
الخطوة 3: الرد يرجع للعميل
═══════════════════════════
                                   │
                                   ▼ يرجع البيانات
                        ┌──────────────────────┐
                        │   List<Product>      │
                        └──────────┬───────────┘
                                   │ يحول لـ XML
                                   ▼
                        ┌──────────────────────┐
                        │  SOAP Response XML   │
                        └──────────┬───────────┘
                                   │
┌─────────────┐                    │
│   العميل    │ ◄──────────────────┘
│   Client    │ يستقبل الرد
└─────────────┘
```

## 🌐 بنية رسالة SOAP بالتفصيل

```xml
<?xml version="1.0" encoding="utf-8"?>

┌─────────────────────────────────────────────────────────┐
│  الغلاف (Envelope) - الحاوية الرئيسية                  │
│  ═══════════════════════════════════════════════════    │
│  <soap:Envelope>                                        │
│                                                         │
│    ┌─────────────────────────────────────────────┐     │
│    │  الرأس (Header) - اختياري                  │     │
│    │  معلومات إضافية (مصادقة، توجيه)           │     │
│    │  ─────────────────────────────────────      │     │
│    │  <soap:Header>                              │     │
│    │    <Authentication>                         │     │
│    │      <Token>xyz123</Token>                  │     │
│    │    </Authentication>                        │     │
│    │  </soap:Header>                             │     │
│    └─────────────────────────────────────────────┘     │
│                                                         │
│    ┌─────────────────────────────────────────────┐     │
│    │  الجسم (Body) - إلزامي                     │     │
│    │  البيانات الفعلية للعملية                  │     │
│    │  ─────────────────────────────────────      │     │
│    │  <soap:Body>                                │     │
│    │                                              │     │
│    │    ┌─────────────────────────────────┐      │     │
│    │    │  العملية المطلوبة             │      │     │
│    │    │  ───────────────────────        │      │     │
│    │    │  <GetProductById>              │      │     │
│    │    │    <productId>1</productId>    │      │     │
│    │    │  </GetProductById>             │      │     │
│    │    └─────────────────────────────────┘      │     │
│    │                                              │     │
│    │  </soap:Body>                               │     │
│    └─────────────────────────────────────────────┘     │
│                                                         │
│  </soap:Envelope>                                       │
└─────────────────────────────────────────────────────────┘
```

## 🔒 الأمان والأخطاء

### معالجة الأخطاء:

```
إذا حدث خطأ:
═════════════

┌─────────────────────────────────────────┐
│        SOAP Fault Response             │
│  (رد خطأ من الخدمة)                    │
├─────────────────────────────────────────┤
│  <soap:Fault>                          │
│    <faultcode>Client</faultcode>       │
│    <faultstring>                       │
│      المنتج رقم 999 غير موجود         │
│      Product 999 not found             │
│    </faultstring>                      │
│    <detail>                            │
│      <ErrorCode>404</ErrorCode>        │
│    </detail>                           │
│  </soap:Fault>                         │
└─────────────────────────────────────────┘

أنواع الأخطاء:
───────────────
Client Error  = العميل أرسل بيانات خاطئة
Server Error  = مشكلة في الخادم
```

## 🎯 مقارنة سريعة: SOAP vs REST

```
┌─────────────────┬─────────────────┬─────────────────┐
│    الميزة       │      SOAP       │      REST       │
├─────────────────┼─────────────────┼─────────────────┤
│  الصيغة         │  XML فقط       │  JSON, XML, etc │
├─────────────────┼─────────────────┼─────────────────┤
│  البروتوكول     │  HTTP, SMTP..  │  HTTP فقط       │
├─────────────────┼─────────────────┼─────────────────┤
│  الأمان         │  WS-Security   │  HTTPS, OAuth   │
├─────────────────┼─────────────────┼─────────────────┤
│  السرعة         │  أبطأ ⚠️       │  أسرع ✅        │
├─────────────────┼─────────────────┼─────────────────┤
│  التعقيد        │  معقد ⚠️       │  بسيط ✅        │
├─────────────────┼─────────────────┼─────────────────┤
│  العقود         │  WSDL تلقائي✅ │  يدوي ⚠️       │
├─────────────────┼─────────────────┼─────────────────┤
│  الاستخدام      │  Enterprise    │  Web/Mobile     │
└─────────────────┴─────────────────┴─────────────────┘

متى تستخدم SOAP؟
─────────────────
✓ البنوك والمؤسسات المالية
✓ الأنظمة الحكومية
✓ التطبيقات الحساسة (أمان عالي)
✓ المعاملات المعقدة

متى تستخدم REST؟
────────────────
✓ تطبيقات الويب والموبايل
✓ APIs العامة
✓ تحتاج سرعة عالية
✓ تطوير سريع
```
