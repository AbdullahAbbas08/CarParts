## 🆘 محتاج مساعدة؟

### إذا ما فهمت شيء:
1. **ارجع للملف التوثيقي** - كل شيء موثق بالتفصيل
2. **اقرأ التعليقات في الكود** - كل سطر معلق بالعربي
3. **جرب الأمثلة** - التطبيق العملي يساعد الفهم
4. **اسأل** - ما في سؤال غبي

### إذا واجهت مشكلة تقنية:
1. **تأكد من .NET 8.0 مثبت**
   ```bash
   dotnet --version
   ```

2. **تأكد من البورت 5002 فاضي**
   ```bash
   # في Linux/Mac
   lsof -i :5002
   
   # في Windows
   netstat -ano | findstr :5002
   ```

3. **شوف الأخطاء في Terminal**
   - اقرأها بعناية
   - غالباً تعطيك الحل
